# Thierry Skill

**An art director for Claude.** This skill makes Claude design websites the way a good studio does: it finds an idea in the client's trade, derives a complete visual system from it, builds the site, then looks at the rendered result and scores it before calling it done.

## The problem

AI agents write correct interface code. What they lack is a point of view. Ask for "a beautiful modern site" and you get the average of every site ever made: the same typeface, the same purple gradient, the same three cards with icons. Nothing is wrong, and nothing is remembered.

Existing design skills mostly polish the surface: easing curves, durations, micro-interactions. That work matters, but it comes last. A site with perfect animations and no idea is still a template.

## What this skill changes

It makes Claude answer three questions, in order, before any effect is added:

1. **What is the idea?** One sentence that says something precise about this client, which a competitor's site could not say.
2. **What is the system?** Typeface, colour, space, shape, image, voice and motion, all derived from that idea.
3. **Is it right on screen?** Screenshots at three widths, measured and scored.

## Art direction, explained

A site is beautiful when three things are true at once:

- **An idea.** It says something specific about its subject.
- **A system.** Every visual choice follows from that idea and the choices answer each other.
- **An execution.** Every invisible detail is right: alignment, states, rhythm, speed, accessibility.

Most sites miss the first and compensate with effects. An effect is never an idea.

The skill looks for the idea in what the trade is made of: its objects, documents, gestures, places, materials, words and measures. A wine merchant has labels and tasting notes. An architect has plans and sections. A lawyer has filings. These forms already belong to the client, so a site built from them cannot be mistaken for anyone else's.

The central test is the **logo swap**: replace the logo with a direct competitor's. If the site still works, there is no idea, and the work starts again.

### Personality as numbers

"Warm", "serious" or "bold" mean nothing to a stylesheet. The skill places seven sliders from 0 to 10 and converts each into concrete parameters: radii, weights, letter-spacing, durations, margins, chroma. Two businesses in the same sector get different settings, which is where made-to-measure comes from.

## It checks its own work

A design judged only by reading code has not been judged. The last step is mandatory: capture, look, score, fix.

`regard.mjs` opens the page in a real browser at three widths. It saves the first screen, the full page, readable slices, a greyscale version and a blurred version, then measures what the eye misses.

Measured on every run: text contrast against WCAG thresholds, horizontal overflow, touch targets under 24 and 44 px, line length, font families and sizes actually rendered, fonts that failed to load, images without dimensions or alt text, heading structure, unlabelled fields, layout shift, and what still moves when the visitor asked for reduced motion.

`audit.mjs` reads the source and flags template habits and execution faults: `transition: all`, entrances from `scale(0)`, removed focus rings, purple gradients, filler text, vague button labels, wrong French punctuation.

Then the page is scored. Under 85, the three heaviest weaknesses are fixed and the page is captured again.

## What you can ask

| You say | The skill delivers |
| --- | --- |
| "Create a site for…" | an art direction sheet, the code, then a review on screenshots |
| "Redo this site" | a diagnosis, what to keep, a new direction, a before and after |
| "What do you think?" | a score out of 100 and ranked corrections, without changing anything |
| "Polish it" | finishing work that leaves the concept untouched |
| "It looks generic", "it looks AI-made" | the list of habits found and what replaces each one |
| "Give me options" | three directions that differ in concept, not in colour |
| "Lovable prompt" | a ready-to-paste prompt for Lovable or any other site generator |

## Install

```bash
npx skills@latest add Jacckisback/thierry-skills
```

Or by hand: copy `skills/thierry-skill` into your project's `.claude/skills/` folder, or into `~/.claude/skills/` to have it everywhere. In the Claude apps, zip the `skills/thierry-skill` folder and upload it in the skills settings.

The two scripts need Node 18 or later. `regard.mjs` also needs Playwright with Chromium:

```bash
npm i -D playwright
```

```bash
npx playwright install chromium
```

## Use

One sentence is enough:

> Use thierry-skill: create the home page for a natural wine shop in Madrid.

The skill is written in French and answers in the language you write in. It builds sites in any language.

Run the scripts yourself at any time:

```bash
node skills/thierry-skill/scripts/regard.mjs http://localhost:3000 --out review
```

```bash
node skills/thierry-skill/scripts/audit.mjs ./src
```

## The goal

Sites that could only belong to their owner. A visitor should be able to describe the site from memory the next day, and the client should recognise their own trade in it. The skill treats beauty as a result of precision: a true idea, a strict system, and proof on screen.

## Limits

- It does not replace the client's content. Without real photos, prices and proof it marks the slots and the score stays capped.
- The sector directions are starting points. Used as they are, they would produce the same site for every business in a sector.
- The scripts give indications to check by eye. They do not test keyboard navigation, form states or screen readers.
- Results depend on the model running the skill and have only been tested on two briefs so far.

## Origin

This skill grew out of a close study of [Emil Kowalski's skills](https://github.com/emilkowalski/skills), which cover animation and interface detail with great precision. It widens the scope to complete art direction and adds verification of the rendered result. All text and code here are original.
